ABOUT INARS

INARSコースとは

INARS（アイナース）は、入院患者さんの「いつもと違う」小さなサインに気づき、心停止などの急変を未然に防ぐための実践的なシミュレーション研修です。

A（気道）・B（呼吸）・C（循環）・D（意識）・E（外表・体温）の順に観察し、急変の前ぶれをとらえる方法を身につけます。看護師をはじめとする医療従事者や看護教育の現場を対象に、観察から報告・応援要請、初期対応（ファーストアクション）までを、チームで繰り返し練習します。
