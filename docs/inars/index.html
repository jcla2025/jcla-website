ABOUT INARS

INARSコースとは

INARS（アイナース）は、入院患者さんの「いつもと違う」小さなサインに気づき、心停止などの急変を未然に防ぐための実践的なシミュレーション研修です。

看護師をはじめとする医療従事者や看護教育の現場を対象に、急変の予兆の観察から、報告・応援要請、初期対応（ファーストアクション）までを、チームで繰り返し練習します。
