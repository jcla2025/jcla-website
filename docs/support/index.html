ご寄付

金額にかかわらず、1回ごとのご支援を受け付けています。いただいたご寄付は、次のような活動に大切に使わせていただきます。

  • 講習用の訓練人形・AEDトレーナーの購入と更新

  • 講習の指導者（インストラクター）の育成
  • 教材・資料の作成

寄付についてメールする

こども救命教育募金

子どもたちに「命をつなぐ力」を届けるために

学校や地域の子どもたちに、救命講習を無料で届けるための募金です。使い道を子ども向けの救命教育に限ったご寄付として、ほかのお金と分けて管理します。

なぜ子どもたちに届けたいのか

突然の心停止は、学校でも、家庭でも、通学路でも起こります。救急車が着くまでの数分間、そばにいる人が胸骨圧迫とAEDを行えるかどうかが、命を左右します。子どものうちに救命を学んだ経験は一生の力になり、学んだ子どもたちが家族に伝えることで、地域の「助けられる人」が増えていきます。視覚に障がいのある子どもたちが学ぶ学校も含め、すべての子どもが救命を学べる機会をつくりたいと考えています。

募金についてメールする

賛助会員

協会の活動に賛同し、継続して支えてくださる個人・団体の方を募集しています。病院や企業など、法人でのご入会も歓迎します。

個人入会金 5,000円／年会費 1口5,000円（1口以上）
団体・法人入会金 10,000円／年会費 1口10,000円（1口以上）

お申込み方法

  1. info@japan-clinical-lifesupport.org まで「賛助会員の入会希望」とお知らせください。入会申込書をお送りします。
  2. 申込書をお送りいただいたあと、入会金・年会費を上記のお振込先へお振込みください。
  3. お振込みの確認をもって入会となります。

お納めいただいた入会金・年会費は、返還いたしませんのでご了承ください。

入会についてメールする

基金

基金は、協会の定款に定めた制度です。活動の土台となる資金をお預かりし、協会が解散するときに利息なしでお返しします。ご寄付と違い、協会の収入ではなく「お預かりするお金」として扱います。募集はご相談をいただいたうえで個別に行っています。

基金のきまりとお申込みの流れ

きまり

  • お預かりした基金は、協会が解散するまでお返ししません。
  • 返還は解散後の清算のときに、協会のほかの債務を支払ったあとで行います。
  • 利息はつきません。お預かりした額を超えてお返しすることもありません。
  • 返還を受ける権利は、社員総会の同意がない限り、譲渡や質入れなどはできません。

お申込みの流れ

  1. info@japan-clinical-lifesupport.org までご相談ください。
  2. 協会から募集要項（募集額・払込期日など）をお送りします。
  3. 申込書をご提出ください。協会から、お引き受けいただく額（割当）をお知らせします。
  4. 期日までにお振込みいただくと、協会から受領書をお送りします。

土地・建物など、金銭以外のご寄付・ご拠出をお考えの方も、まずはご相談ください。
