お申し込み・お問い合わせ

ご用件に合わせて、いちばん近い窓口をお選びください。

どなたでも・個人で講習会に参加したい開催予定の一覧から日程を選び、各講習会の申込フォームからお申し込みください。日程と申込方法 学校・企業・団体・病院出張講習・院内開催を依頼したい下の「ご依頼の方法」をご覧のうえ、メールかLINEでご連絡ください。ご依頼の方法 医療従事者・看護教育INARSコースを受けたい各コースの申込はMeCCSOの申込ページで受け付けています。開催予定と申込 講習会を一緒に支えたい方ボランティアに参加したい講習会当日の運営や準備・片付けのお手伝いです。ボランティア実績証を発行します。募集フォームへ
REQUEST

出張講習・院内開催のご依頼

次の項目をお知らせいただくと、プランと費用のご提案がスムーズです。わかる範囲で構いません。

  • 団体名・ご担当者名・連絡先
  • ご希望の日時（候補を2〜3つ）
  • 受講人数と、対象の方（年齢・職種など）
  • 会場（住所）と、床に座れるスペースの有無
  • ご希望の時間（90分／180分）やご要望

ご寄付のお願い

私たちの活動は、皆様からの温かいご支援・ご寄付によって支えられています。お寄せいただいた寄付金は、講習活動の維持・拡大、救命資器材の充実のために大切に使用させていただきます。

「救える命を、救える社会に」していくため、皆様のご理解とご協力を心よりお願い申し上げます。
