# お問い合わせフォームの受付設定（最初に1回だけ）

ホームページのお問い合わせフォームは、協会のGoogleアカウントに置いた受付の仕組み（Apps Script）へ送信されます。
送信内容はスプレッドシート「HPお問い合わせ」にたまり、info@ にお知らせメールが届きます（返信ボタンで相手に直接返信できます）。

## 手順（パソコンで。15分ほど）
1. 協会のGoogleアカウント（asagoe@japan-clinical-lifesupport.org）で Googleドライブを開き、新しいスプレッドシートを作って名前を「HPお問い合わせ」にする。
2. メニューの「拡張機能」→「Apps Script」を開く。最初からある中身を消し、`contact.gs` の中身をすべて貼り付けて保存（💾）。
3. 上の関数の選択で `testSubmit` を選び「実行」。「権限を確認」→ アカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」。
   スプレッドシートに「受付」シートとテストの1行ができ、info@ にメールが届けばOK。
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
   「デプロイ」を押し、表示された「ウェブアプリのURL」（https://script.google.com/macros/s/…/exec）をコピーする。
5. そのURLを Claude に渡す → `src/content.py` の `FORM_ENDPOINT` に入れて公開すると、サイトにフォームが表示される。

## あとから中身を直したとき
「デプロイ」→「デプロイを管理」→ 鉛筆ボタン → バージョン「新しいバージョン」→「デプロイ」。URLは変わらない。
